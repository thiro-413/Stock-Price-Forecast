# Stock-Price-Forecast

株価データの分析と将来の株価予測を行うためのプロジェクトです。

## 現在の状態

研究コードと収集・検証結果は `work/stock_research/` に保存しています。Python 3.12 の標準ライブラリを使用します。

- 対象：2026年6月の事後研究、2026年7月の各営業日08:30（日本時間）を仮定した予測検証。東証普通株・前日終値比上位10。
- 6月：22営業日分の事後研究を完了。原因不明の事例も記録しています。
- 7月：7月16日までの12営業日、120予測を比較済み。上位10入りは14件（11.7%）。直近3日分は3/30件（10.0%）。次回は7月17・21・22日（20日は休場）。
- 詳細な不的中原因分析は7月全営業日の比較後。最後のスクリーニング用プロンプト作成には別途ユーザー確認が必要です。

候補は前日5%以上上昇銘柄と取得ニュース掲載銘柄の部分集合です。全東証の網羅検証ではありません。入力情報は各日08:30以前に限定していますが、調査中の将来記事の偶発表示を記録しており、厳密な未見検証・将来情報遮断の実証とは呼びません。第三者集計を照合した参考検証であり、売買収益率を示すものではありません。

## ファイルと実行

- `PROTOCOL.md`：研究手順、時刻制限、データ不足・逸脱の記録。
- `data/`：固定モデル、予測入力、実績。
- `evidence/`：取得した出典の記録。掲載日時と取得時点は区別し、予測への適格性は各入力で管理します。
- `results/`：日別予測・採点・比較、3営業日単位のJSON/CSV/Markdown、整合性確認用ハッシュ。
- `results/state.json`：進捗と次の対象日。

リポジトリのルートから `python work/stock_research/july_predict.py YYYY-MM-DD` で、準備済みの入力を採点して予測を保存します。既存の予測は上書きできません。固定済みモデルを再固定・変更しないでください。ニュース取得・原資料の照合・材料分類には対話での調査が必要で、完全自動取得システムではありません。

報告書の再生成スクリプトは `finalize_july_batch01.py` ～ `finalize_july_batch04.py`。過去バッチの再実行は進捗状態を書き戻すため、必要な場合のみ実行してください。

最新の結果：[7月第4回の報告書](work/stock_research/results/july_batch04_report.md) ／ [全30予測の比較CSV](work/stock_research/results/july_batch04_predictions.csv)。

## 継続時の保存方針

2026年10月16日のユーザー指示に基づき、各3営業日の処理完了ごとに変更をコミットし、`origin/main` にプッシュします。完了報告後、次の3営業日へ進むかを確認します。プッシュの失敗は成功扱いせず、原因と保存済み状態を報告します。以後の作業保存先はこのリポジトリです。

今後は7月の残り10営業日の比較、全22営業日の不的中原因分析を各3営業日単位で進めます。全処理完了後、確認を得てスクリーニング用プロンプトを作成します。

## 注意事項

本プロジェクトは学習・研究を目的としています。予測結果は将来の株価を保証するものではなく、投資助言ではありません。
